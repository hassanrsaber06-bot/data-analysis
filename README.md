# 📈 Marketing Data Analysis

## 📌 Overview
A comprehensive analysis of a marketing campaign dataset, covering data cleaning,  
exploratory data analysis, and an interactive Power BI dashboard.

## 🎯 Objectives
- Clean and preprocess marketing data
- Discover customer segments and campaign performance
- Visualize key KPIs in a Power BI dashboard
